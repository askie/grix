# Code of Conduct

We are committed to a respectful, welcoming, and harassment-free community.

Contributors should communicate constructively, assume good intent, respect
different backgrounds and levels of experience, and focus criticism on ideas
and code rather than people. Harassment, threats, discriminatory language,
doxxing, and deliberate disruption are not acceptable.

Maintainers may edit or remove contributions and restrict participation when
behavior conflicts with these expectations. Report conduct concerns privately
through the repository's security or maintainer contact channels rather than
in a public issue.
