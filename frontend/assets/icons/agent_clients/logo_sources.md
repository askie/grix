# Agent Client Logo Sources

- `openai.svg`, `anthropic.svg`, `googlegemini.svg`, `qwen.svg`, `cursor.svg`: [Simple Icons CDN](https://simpleicons.org/). (`openai.svg` is used for the `codex` client type; `cursor.svg` is the official Cursor mark.)
- `openclaw.svg`, `opencode.svg`, `github-copilot.svg`: [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons).
- `kiro.svg`: [kiro.dev](https://kiro.dev/).
- `hermes.svg`, `reasonix.svg`, `codewhale.svg`, `openhuman.svg`: local fallback marks for products without a stable public static logo URL at implementation time.
- `pi.svg`: local fallback mark for [Pi](https://github.com/earendil-works/pi) (`@earendil-works/pi-coding-agent` on npm). No public brand logo available at implementation time.
- `agy.svg`: official [Antigravity](https://antigravity.google/) mark, via [Lobe Icons](https://github.com/lobehub/lobe-icons) (verified against `antigravity.google`'s favicon).
- `kimi.svg`: official [Kimi](https://www.kimi.com/) mark (Moonshot AI), via [Lobe Icons](https://github.com/lobehub/lobe-icons) (verified against `kimi.com`'s favicon).
- `deepseek.svg`: [Simple Icons CDN](https://simpleicons.org/) (official DeepSeek mark, brand color `#5786FE`).
- `qoder.svg`: official [Qoder](https://qoder.com/) mark, via [Lobe Icons](https://github.com/lobehub/lobe-icons) (`icons-static-svg` package, `qoder.svg`). Shared by both `qodercli` and `qoderclicn` client types — Qoder CLI CN is Alibaba's CN-region distribution of the same product, no separate CN mark found.
- `minimax.svg`: [Simple Icons CDN](https://simpleicons.org/) (official MiniMax mark, brand color `#E73562`). Used for the `mcode` client type (MiniMax Code CLI).
- `dim.svg`: **local text placeholder**, not an official mark — no public logo found for DimAgent/dimcode at implementation time (checked Simple Icons and Lobe Icons, both 404). Same style as the existing `pi.svg` fallback (colored rounded-square plate + monogram text). Replace with the official mark if/when one becomes available.
- `trae.svg`: [Simple Icons CDN](https://simpleicons.org/) (official TRAE mark, brand color `#32F08C`). Used for the `traecli` client type — the official TraeCode CLI (docs.trae.cn/cli), a standalone product sharing ByteDance's TRAE brand mark; not the TRAE IDE app icon.
- `codebuddy.svg`: [Simple Icons CDN](https://simpleicons.org/) (official CodeBuddy mark, brand color `#6C4DFF`). Used for the `codebuddy` client type (Tencent CodeBuddy Code CLI).
- `omp.svg`: **local text placeholder**, not an official mark — no public logo found for Oh-My-Pi/omp at implementation time (checked Simple Icons and Lobe Icons, both 404). Same style as the existing `pi.svg`/`dim.svg` fallback (colored rounded-square plate + monogram text) — deliberately a different color/glyph from `pi.svg` so the two don't look identical in the client type picker despite omp reusing the pi adapter. Replace with the official mark if/when one becomes available.
- `grok.svg`, `qwenpaw.svg`, `zeroclaw.svg`: local fallback marks (monogram on a rounded-rect plate, same style as `pi.svg`/`reasonix.svg`) — no stable public static logo URL found at implementation time (`cdn.simpleicons.org/grok` 404s; QwenPaw and ZeroClaw are not in Simple Icons or Dashboard Icons). **待官方素材替换 / pending replacement with an official mark** if/when one becomes available.
