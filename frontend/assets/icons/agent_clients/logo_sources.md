# Agent Client Logo Sources

- `openai.svg`, `anthropic.svg`, `googlegemini.svg`, `qwen.svg`, `cursor.svg`: [Simple Icons CDN](https://simpleicons.org/). (`openai.svg` is used for the `codex` client type; `cursor.svg` is the official Cursor mark.)
- `openclaw.svg`, `opencode.svg`, `github-copilot.svg`: [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons).
- `kiro.svg`: [kiro.dev](https://kiro.dev/).
- `hermes.svg`, `reasonix.svg`, `codewhale.svg`, `openhuman.svg`: local fallback marks for products without a stable public static logo URL at implementation time.
- `pi.svg`: local fallback mark for [Pi](https://github.com/earendil-works/pi) (`@earendil-works/pi-coding-agent` on npm). No public brand logo available at implementation time.
- `agy.svg`: official [Antigravity](https://antigravity.google/) mark, via [Lobe Icons](https://github.com/lobehub/lobe-icons) (verified against `antigravity.google`'s favicon).
- `kimi.svg`: official [Kimi](https://www.kimi.com/) mark (Moonshot AI), via [Lobe Icons](https://github.com/lobehub/lobe-icons) (verified against `kimi.com`'s favicon).
- `deepseek.svg`: [Simple Icons CDN](https://simpleicons.org/) (official DeepSeek mark, brand color `#5786FE`).
